## Constraints and review focus

No cloud writes, paid LLM calls, SQLite transfer, deployment or push. No destructive migrations.
Keep SQLite compatibility for upstream and regression tests, PostgreSQL for target deployments.
Check cross-user access, expired sessions, storage/SQL partial failure, interrupted tasks and fresh migrations.

Create a frozen PostgreSQL baseline before the existing Alembic chain, without rewriting history. Test empty database and repeat upgrade, constraints and independent transactions.

Each code task starts with regression tests of its public behavior, then implementation and targeted verification. Cloud integration remains opt-in with explicit test credentials. DEPLOYMENT.md must distinguish working code from unverified cloud behavior and give exact PowerShell commands and secret names.
